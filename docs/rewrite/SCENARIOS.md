# Rewrite test matrix — decision core

Every row is one objective, automatable test. `REAL` marks a failure actually observed on this install (git/docs/memory/live-diagnostics reference in the cell); `no` means a designed guard/property with no known live incident. Values are concrete: prices EUR/kWh, powers W, energies kWh, SoC %, timestamps UTC (local time stated where used). `unit` = pure function, `integration` = module wiring with fakes, `regression` = replay of the real failure, `fault` = injected telemetry/transport fault, `property` = invariant over generated inputs, `contract` = API/ledger shape. All scenarios target the pure-Rust rewrite, not the C core.
