1. **High — `M5.md`, CURRENT ladder and INTENDED precedence:** Emergency charging has no defined conflict policy. The forced target still passes through authority, plan-tracking, ramp, and grid bounds; missing grid telemetry blocks the whole pack. The intended *reporting* order does not establish execution precedence. **Impact:** ordinary constraints can prevent cell protection, or implementers may incorrectly override hard limits. **Required change:** specify which constraints may restrict each cell-safety action, how incompatible hard limits resolve, and what protective action and fault are emitted when emergency charging is impossible.

2. **High — `M5.md`, INTENDED “own write lane”:** Independence from the protected write path is asserted but not specified. CURRENT explicitly bypasses backoff only for latched-cell neutral holds and emergency charges; the contract does not cover import-guard actions, ordinary suppression/deduplication, or failures within the safety lane itself. **Impact:** a necessary safety write can still be suppressed or share the failure state it must bypass. **Required change:** enumerate safety-lane actions and bypass rules, separate their retry/receipt state from ordinary dispatch, and define retry and escalation when a protective write fails or remains unverified. Preserve dry-run’s no-write guarantee.

3. **High — `M5.md`, safety-ladder coverage:** Orphan hold, cancel ramp, 120-second restart grace, and no-command-standing behavior are absent. **Impact:** this specification cannot establish that stale hardware commands are neutralized during ownership loss, cancellation, or restart—or that restart grace does not delay cell protection. **Required change:** define these transitions, their precedence against cell and import guards, and whether each transition requires an explicit verified neutral write rather than merely issuing no new command.

4. **Medium — `M5.md`, acceptance conditions:** The safety contract has no acceptance matrix for simultaneous hazards or write-path failure. Source references and one historical regression do not validate the proposed ladder. **Required change:** require tests for latched discharge with active backoff, emergency charge with conflicting bounds or missing telemetry, import breach with a latched/empty pack, and orphan/cancel/restart transitions with a standing nonzero command. Assert the resulting action, bypass behavior, verification outcome, and complete ordered reasons.

**Verdict: approve with required changes — resolve items 1–4 before implementation approval.**
